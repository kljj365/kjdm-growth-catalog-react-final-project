# Course-Spec and Tailored-Original Separation Plan

## Purpose

The project set contains two different kinds of work. The **course-spec reconstruction** is a private learning artifact designed to demonstrate the sections and behaviors taught in the Frontend Simplified e-portfolio lessons. The **tailored original portfolio** is the public-facing Signal Ledger site and its original project routes, built for Kyle Johnson Digital Marketing, résumé use, GitHub discussion, and business-development conversations.

| Requirement | Course-spec reconstruction | Tailored original portfolio |
|---|---|---|
| Location | `study-references/eportfolio-course-spec/` | Public portfolio root and project routes |
| Purpose | Practice the course’s visible navigation, hero, technology grid, project overlays, footer, and responsive patterns | Demonstrate original frontend reasoning, business-relevant interfaces, and a personal visual system |
| Attribution | Private study reconstruction based on publicly visible course/tutorial behavior | Kyle Johnson original work, with no claim that course references are client delivery |
| Visual identity | Instructional clean-room reference, deliberately separated by a persistent study notice | Signal Ledger: paper, ink navy, restrained signal orange, evidence-led case-study treatment |
| Data and copy | Non-client practice content | Original project descriptions, public sample-data disclaimers, and business-service evidence |
| Appropriate sharing | Personal study and a mentor conversation only when the mentor requests course work | Résumé, GitHub, client conversation, and business portfolio |

## Course-spec acceptance checklist

The private reconstruction includes the following visible course behaviors: a navigation bar with anchor links and contact action; a centered introductory hero with profile cue, social links, and decorative illustration; a technology grid with hover labels; project cards whose overlay appears on hover; footer navigation; and mobile breakpoints that change nav visibility, project overlay layout, and technology-grid columns.

## Tailored-original acceptance checklist

The Signal Ledger public portfolio uses distinct design, branding, code structure, and project content. Its original routes cover an API search interface, product discovery and commerce interactions, operational workflow filtering, booking selection and confirmation, and a public-sample-data directory. It does not reuse David Bragg’s image, logo, résumé, project screenshots, project copy, or source code.

## Submission and presentation boundary

Kyle Johnson personally chooses and submits the appropriate course-spec link only after reviewing the mentor’s rubric. The public portfolio should be used in hiring and business contexts. Both contexts should describe the work accurately: course reconstruction for learning, original routes for public proof of implementation skill.
